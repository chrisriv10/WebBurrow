# WebBurrow 1.0.0 — Playable Home

Improved release build: 2026-08-29

WebBurrow 1.0.0 is the first stable local product contract: a cohesive spatial homepage, fast keyboard launcher, persistent personal organization layer, optional public-data surfaces, optional browser companion, and an installable Windows shell.

## Release highlights

- Home Den, Developer Studio, and Media Lounge now have distinct footprints, circulation, furniture, lighting, mounting anchors, colliders, and matching Mini Burrow geometry.
- Temporary browser sessions materialize as clearly labeled Studio workspaces and stay entirely outside persistent storage until the user promotes them.
- Weather, calendar, GitHub, feeds, notes, favorites, recents, and browser sessions have purpose-built physical summaries plus accessible HTML detail surfaces.
- Room customization, thirteen object archetypes, contextual mounts, valid-placement recovery, duplication, undo, and configuration V3 make the Burrow portable and resilient.
- The Windows app adds exact-origin native messaging, validated deep links, an optional system tray, explicit same-origin favicon retrieval, and hidden-window suspension.
- Every site archetype now has a constructed procedural identity, while approach, selection, arrival, launch, and valid/invalid placement states stay subtle and legible.
- Browser workspaces adapt from individual stations to labeled banks and instanced dense racks, with deterministic group/domain arrangement and focused-item ordering.

## Data compatibility

Dexie schema 5 and ConfigEnvelope V3 migrate prior room, object, collection, preference, note, activity, and integration definitions. Layout version 3 deterministically maps legacy placements into the authored room footprints and resolves blocked positions through stable anchors. Configuration imports accept V1 and V2 and emit V3. Caches, errors, notifications, browser identity, temporary rooms, and icon blobs remain excluded from exports.

Generated binaries and raw QA output are intentionally not committed.

## Honest limitations

- Windows is the only packaged target. First-person controls assume a keyboard and mouse.
- The installer is unsigned and the extension must be manually loaded unpacked.
- Web subscriptions require source CORS support. GitHub is public-only and subject to unauthenticated rate limits.
- There is no account, backend, cloud sync, telemetry, authenticated integration, social feature, OS notification, or extension-store publication.
- The measured QA targets are hardware- and driver-dependent. This pass met the specified draw-call and arrival-task ceilings and enforced hidden-work suspension; observed p95 frame time varied between roughly 35–47 ms for the default room and 39–69 ms for the 100-tab case on the shared QA machine, so a locked 60 FPS is not claimed.
